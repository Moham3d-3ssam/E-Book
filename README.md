# 📚 E-Book - Online Book Store

A modern, responsive e-book store website featuring a clean design and smooth user experience. Browse and explore a collection of e-books with featured books, new arrivals, special discounts, and customer testimonials.

## ✨ Features

- **Responsive Design** - Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Dark Mode** - Toggle between light and dark themes with persistent preference storage
- **Interactive Navigation** - Smooth scrolling navigation with active section highlighting
- **Book Carousels** - Beautiful swiper carousels for featured books and new releases
- **Search Functionality** - Quick search bar to find your favorite books
- **User Authentication UI** - Login form interface for user account access
- **Discount Section** - Special promotional section highlighting up to 50% discounts
- **Customer Reviews** - Testimonials section showcasing customer opinions
- **Scroll Animations** - Engaging scroll reveal animations throughout the page
- **Newsletter Subscription** - Email subscription form for latest updates

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with custom properties and animations
- **JavaScript (ES6+)** - Interactive functionality and DOM manipulation
- **[Swiper.js](https://swiperjs.com/)** - Touch slider for carousels
- **[ScrollReveal](https://scrollrevealjs.org/)** - Scroll animations library
- **[Font Awesome 6.6.0](https://fontawesome.com/)** - Icon library

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Moham3d-3ssam/E-Book.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd E-Book
   ```

3. **Open in browser**
   - Simply open `index.html` in your web browser, or
   - Use a local development server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js (with http-server)
     npx http-server
     ```

4. **Access the website**
   - Open your browser and navigate to `http://localhost:8000` (if using a local server)
   - Or directly open the `index.html` file

## 💡 Usage

### Navigation
- Use the navigation menu to jump to different sections (Home, Features, Discount, New Books, Testimonials)
- Click the moon/sun icon to toggle between light and dark modes
- Use the search icon to open the search bar
- Click the user icon to access the login form

### Sections
- **Home** - Hero section with featured book carousel
- **Services** - Highlights of free shipping, secure payment, and 24/7 support
- **Featured Books** - Carousel showcasing featured book collection
- **Discount** - Special promotional offers (up to 50% off)
- **New Books** - Latest book arrivals with ratings
- **Testimonials** - Customer reviews and feedback
- **Footer** - Additional information and social links

## 🎨 Customization

### Colors
The color scheme can be modified in the `css/main.css` file using CSS custom properties.

### Content
- Update book images in the `images/` folder
- Modify text content in `index.html`
- Adjust carousel settings in `js/master.js`

### Animations
- Configure ScrollReveal animations in `js/master.js`
- Adjust Swiper carousel options in `js/master.js`
